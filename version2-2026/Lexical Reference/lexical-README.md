# Lexical Reference — version2-2026

Underlying package fields remain f1/f2/f3 for runtime compatibility; the validator may present them to users as K1/K2/K3.

Rules: F1=df1, F2=df2, F3=df3, 4+=excluded. Eligibility is >=1 F1 OR >=2 F2 OR >=3 F3. Routes are independent. Bloom action openers and configured stop words are excluded. Course frequency is calculated across full courses only. SDG frequency is calculated across 17 SDG entities after combining each goal with its targets.
